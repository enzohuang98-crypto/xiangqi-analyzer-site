運作方式

引擎負責算，你負責想，AI 只負責把話講清楚。

01

引擎先算

本機引擎在你自己的電腦上跑，即時給出深度、分數與候選著。 不用網路、不用付費，棋局也不會離開這台電腦。

免費・開箱即用
02

你先猜一手

在看到答案前先鎖定自己想走的棋，軟體才揭曉引擎的最佳著法， 並算出兩者差幾分。練的是判斷力，不是背答案。

引擎與 AI

不綁定單一服務

實際相容性仍依引擎版本、協定實作與模型供應商政策而定。

本機引擎

UCI / UCCI

Pikafish 隨安裝檔附贈、開箱即用；另可連接 Px0、象棋名手、象棋旋風、 象棋小蟲、烏雲象棋、阿爾法貓等 UCI／UCCI 引擎，或自訂設定檔。

  • 只有 Pikafish 隨附，其餘引擎執行檔須自行合法取得
  • 可設定主要與複核引擎，判斷不一致時會提示
  • 加入後先測試協定與連線狀態再啟用
雲端 AI（選配）

Claude / OpenAI / Gemini

AI 只負責解釋引擎給出的結構化資料，不參與棋力判斷， 也不會發明引擎沒算出來的著法。

  • 自行申請 API 金鑰，以 Windows 加密機制存在本機
  • 費用由各服務商直接計價，與本軟體無關
  • 完全不啟用 AI 也能正常分析棋局

常見問題

下載前先知道

安裝時 Windows 跳出藍色警告，正常嗎？

正常。本專案目前還沒有購買受信任 CA 的程式碼簽章憑證，Windows SmartScreen 對所有未簽章的軟體都會顯示「未知發行者」，不分好壞，這不代表軟體被竄改。 你可以用頁面上公開的雜湊值核對檔案，或看 使用說明的對應章節。

軟體有附象棋引擎嗎？

有一顆：Pikafish 隨安裝檔附贈，免費、開箱即用（引擎本體採 GPLv3，NNUE 權重檔另有非商業使用限制）。其餘引擎如象棋名手、旋風、小蟲等需自行取得 合法授權的執行檔，在設定頁指定路徑即可連接。

一定要付 AI API 費用嗎？

不用。只用本機引擎分析是完全免費的；只有在你主動要求 AI 中文解釋時， 才會呼叫你自己設定的服務並使用你的額度。

我的棋局會被上傳嗎？

引擎分析全程在你的電腦上完成，不會傳送到任何伺服器。只有在你啟用 AI 解釋時，該次局面資料才會依你的選擇送往對應的 AI 服務商。

裝了之後要自己回站上抓新版嗎？

通常不用。軟體啟動後及之後每 4 小時會自動檢查更新，發現新版會在背景下載， 並在下次重新啟動前提醒你安裝；當然也可以隨時回本站下載最新安裝檔覆蓋安裝。

支援哪些作業系統？

目前只支援 Windows 10（22H2 以上）與 Windows 11，其他平台尚未列入正式支援。
