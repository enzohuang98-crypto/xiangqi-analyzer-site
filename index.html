核心功能

從擺棋到理解，一個畫面完成

保留引擎的專業資訊，同時降低閱讀門檻。

01 深度

即時引擎分析

顯示分析進度、深度、評分、候選著與原始輸出，不必等待整段分析結束才知道狀態。

分析深度

02 中文

中文棋理解釋

將引擎符號整理成局面判斷、風險、計畫與可追問的自然語言。

03 猜著

猜著模式

看到答案前先自己選一步，鎖定後才顯示引擎最佳著法並比較分差，練你自己的判斷力。

04 複核

雙引擎複核

設定主要與複核引擎，兩者意見不一致時提示你，避免單一引擎的誤判被當成標準答案。

05 收藏

待理解局面收藏

把還沒想通的關鍵局面收進「待理解」清單，之後隨時回到工作台繼續追問，直到真的搞懂。

快速開始

第一次使用

引擎與 AI 服務都由使用者自行選擇，軟體不提供引擎授權，也不包含 AI 額度。 完全不熟電腦操作也沒關係， 這裡有逐步、新手也看得懂的完整說明。

  1. 1

    安裝 Windows App

    從本網站下載已標示版本號與雜湊、可供核對的安裝檔（GitHub Releases）。

  2. 2

    開箱即用的本機引擎

    安裝檔內建 Pikafish，第一次開啟就能分析；想加入其他引擎，在設定頁指定 執行檔路徑即可。

  3. 3

    選擇性設定 AI

    貼上你自己的 API Key。只有使用 AI 中文解釋時才會呼叫對應服務並產生費用。

  4. 4

    擺局、猜著、看懂

    從棋盤、FEN 或棋譜建立局面，可以先自己猜一手，再對答案看引擎怎麼想。

引擎與 AI

不綁定單一服務

實際相容性仍依引擎版本、協定實作與模型供應商政策而定。

本機引擎

UCI / UCCI

Pikafish 隨安裝檔附贈、開箱即用；另可連接 Px0、象棋名手、象棋旋風、象棋小蟲、 烏雲象棋、阿爾法貓等多顆 UCI/UCCI 引擎，或自訂設定檔。

  • 只有 Pikafish 隨附，其餘引擎執行檔需自行合法取得
  • 可設定主要與複核引擎，雙引擎意見不一致時會提示
  • 執行前測試協定與連線狀態
雲端 AI

Claude / OpenAI / Gemini

AI 只負責解釋結構化引擎資料，不取代引擎做棋力判斷。

  • 使用者自行申請 API Key，以本機加密儲存
  • 費用由各 Provider 直接計價
  • 可只用本機引擎、不啟用 AI

常見問題

下載前先知道

現在可以下載嗎？

可以，安裝檔已發布在 GitHub Releases，版本號與雜湊會由自動化流程持續同步顯示在 上方。目前尚未取得受信任的程式碼簽章憑證，Windows 可能會顯示「未知發行者」的 SmartScreen 警告，這不代表軟體有問題；詳見使用說明的對應章節。

軟體有附象棋引擎嗎？

有一顆：Pikafish 隨安裝檔附贈，免費、開箱即用（引擎本體 GPLv3，NNUE 權重檔另有非商業使用限制）。其餘引擎（象棋名手、旋風、小蟲等）需自行取得合法授權的 執行檔，在設定頁指定路徑即可連接。

一定要付 AI API 費用嗎？

不一定。可只使用本機引擎分析；啟用 AI 中文解釋時，才會使用你的 API 額度。

裝了之後要自己回站上抓新版嗎？

通常不用。軟體會在啟動後與之後每 4 小時自動檢查一次更新，發現新版會背景下載， 下次重新啟動前提醒你安裝；也可以隨時回本站抓最新安裝檔重新覆蓋安裝。

支援哪些作業系統？

目前只支援 Windows 10（22H2 以上）與 Windows 11，其他平台尚未列入正式支援。
